# WriteLoop 활성 질문 전수 수동 검토 보고서

## 1. 결론

2026년 7월 23일 기준 활성 질문 675개를 질문 문구, 한국어 번역, 팁·힌트, 필수·선택 슬롯, 질문별 의미 계약과 함께 하나씩 검토했다.

- 수정이 필요했던 질문: 220개
- 검토 후 그대로 유지한 질문: 455개
- 영어 질문 수정: 195개
- 한국어 질문 수정: 220개
- 질문 팁 수정: 2개
- 시작 문장 등 구조화 힌트 수정: 5개
- 비활성화하거나 새 ID로 교체한 질문: 0개

질문이나 슬롯을 정규식·LLM·생성기로 새로 분류하지 않았다. 변경 대상과 슬롯 조합은 모두 `094` 마이그레이션에 ID 단위로 명시했다.

## 2. 검토 기준

각 활성 질문에는 다음 기준을 동일하게 적용했다.

1. 질문만 읽어도 답변해야 할 대상과 관계를 알 수 있어야 한다.
2. 하나의 자연스러운 학습 의도로 해석돼야 한다.
3. 질문이 직접 요구하는 요소와 필수 슬롯이 일치해야 한다.
4. 숨은 추가 요구를 `minimumDepthSlots`로 강제하지 않아야 한다.
5. 영어와 한국어가 같은 범위와 관계를 질문해야 한다.
6. 팁과 시작 문장은 수정된 질문에 그대로 사용할 수 있어야 한다.
7. 난이도와 질문 풀이 수는 유지해야 한다.

### 3.1 추상적이거나 어색한 질문

통근 지연 질문은 무엇을 답해야 하는지 모호한 기존 문장을 다음처럼 바꿨다.

- 변경 전: `Describe a problem you sometimes have with handling commuting delays and explain what you do about it.`
- 변경 후: `What commuting delay do you sometimes experience, and what do you do when it happens?`

학습자는 이제 자신이 겪는 지연 상황과 대처 행동을 순서대로 답하면 된다. `PROBLEM` 계약도 지연의 결과만이 아니라 늦은 열차, 교통 체증, 환승 실패처럼 구체적인 지연 자체를 인정하도록 맞췄다.

### 3.2 여러 방향으로 해석되던 질문

광범위한 사회적 책임 질문은 역할 하나와 그 이유를 답하도록 범위를 명확히 했다.

- 변경 전: `What responsibilities should social media platforms have in modern society?`
- 변경 후: `What is one important responsibility social media platforms should have, and why?`

의견 질문 36개에 같은 원칙을 적용해 `OPINION`과 `REASON`의 관계가 질문에 직접 드러나도록 했다.

### 3.3 질문에 보이지 않던 슬롯

기존 질문은 짧은 답을 허용하면서 메타데이터만 이유·예시·결과를 추가로 요구하는 경우가 있었다.

- 변경 전: `What kind of person are you?`
- 변경 후: `What kind of person are you, and what is one example that shows it?`

입문 질문은 필요한 두 번째 요소가 이유라면 `and why?`, 결과라면 `how does it help?`, 추가 행동이라면 `two things`처럼 질문에 직접 표시했다.

### 3.4 영어·한국어 불일치

한국어 220개를 모두 다시 확인했다. 영어의 대상, 시제, 수량, 질문 관계가 한국어에도 동일하게 나타나도록 수정했다. 영어는 자연스럽지만 번역만 어색했던 25개는 영어를 유지하고 한국어만 고쳤다.

### 3.5 팁과 힌트

질문을 바꾼 뒤 기존 시작 문장이 다른 답을 유도하지 않도록 핵심 질문, 목표 질문 3개, 통근 지연 질문의 힌트를 함께 수정했다. 예를 들어 빠른 식사 질문의 시작 문장은 `choose`가 아니라 실제 조리 행동을 나타내는 `make`를 사용한다.

## 4. 슬롯 계약 정렬

질문에서 새로 명시한 두 번째 요구 137개를 최종적으로 모두 활성 `REQUIRED` 슬롯으로 강제했다.

| 필수 대상 슬롯 | 질문 수 |
|---|---:|
| `REASON` | 118 |
| `RESULT` | 10 |
| `ADDITIONAL_ACTION` | 4 |
| `ACTION` | 2 |
| `EXAMPLE` | 1 |
| `PLACE` | 1 |
| `PROBLEM` | 1 |
| 합계 | 137 |

`093` 기준에서 133개는 이미 필수 슬롯이었고 4개가 실제 `OPTIONAL → REQUIRED` 전환 대상이었다. `094`는 환경별 과거 데이터 차이와 무관하게 137개 조합이 모두 필수 상태가 되도록 멱등적으로 처리한다.

추가로 다음을 반영했다.

- 137개 질문의 `minimumDepthSlots`를 0으로 내려 질문에 보이지 않는 추가 요구를 제거했다.
- 이미 설명과 이유를 필수로 묻는 고급 일반 질문 16개의 추가 깊이 요구를 0으로 조정했다.
- 통근 지연 질문의 `PROBLEM` 충족 기준을 수정했다.
- 거주 지역 선호 질문의 질문별 의미 역할을 도시 이름이 아니라 실제 거주 지역의 구체적 특징·장소·경험으로 정렬했다.

## 5. 적용 방식

- 기존 `085~093` 마이그레이션과 수동 메타데이터 JSON은 수정하지 않았다.
- 새 업데이트 파일 `094-manually-revise-active-prompt-questions.sql`만 추가했다.
- 질문 ID를 유지했고 스냅샷 테이블이나 새 질문을 만들지 않았다.
- Java에서 직접 시드하는 `prompt-a-2`는 서버 재시작 시 되돌아가지 않도록 `PromptSeedConfig`도 같은 문구로 맞췄다.
- 답변 기록은 과거 질문 스냅샷이 아니라 현재 `prompts` 문구를 계속 조회한다. 따라서 과거 기록에서도 수정된 질문이 보이는 것은 이번 결정의 의도된 결과다.
