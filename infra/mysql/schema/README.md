# 예전 마이그레이션 (001~107, 동결)

이 폴더는 Flyway 도입 전에 손으로 적용하던 번호순 SQL 마이그레이션이다. 2026-10-22에 107번에서 동결했다.

- 새 스키마·데이터 변경은 `apps/backend/src/main/resources/db/migration`에 Flyway 버전 파일(`V번호__설명.sql`)로 추가한다.
- 이미 있던 DB는 Flyway가 처음 실행될 때 `107`로 기준선 표시만 하고, 이 폴더의 파일은 다시 실행하지 않는다.
- 빈 DB는 이 폴더가 아니라 `V107__baseline.sql`(운영 DB 구조와 기준 데이터 덤프)부터 만든다.
- 이 폴더의 파일을 빈 DB에 순서대로 실행하면 운영과 같은 구조가 나오지 않는다. 2026-10-22 확인 결과는 다음과 같다.
  - 실패하는 파일이 11개 있다. 이미 적용한 뒤 수정된 파일, 앱 시작 시 만드는 데이터에 의존하는 파일이 원인이다.
  - 코드가 쓰는 컬럼 1개가 빠진다.
  - 타입이 다른 컬럼이 생긴다.
- 그래서 이 폴더는 변경 이력을 보는 기록용으로만 남긴다. 자세한 내용은 `docs/decisions/0013-adopt-flyway-with-production-baseline.md`를 본다.
